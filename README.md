# Description

Este proyecto permite obtener un xml con los datos obtenidos de una plantilla excel.

# Instalación

Para instalar el proyecto es necesario tener instalado en el sistema el siguiente software:

- Node.js
- NPM

Una vez instalados los software, se puede instalar el proyecto con el siguiente comando:

```bash
npm install
```

# Uso

Una vez instalados los software, se puede ejecutar el proyecto con el siguiente comando:

```bash
npm start
```
